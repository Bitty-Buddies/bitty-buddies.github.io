# bitty-buddies.github.io

Builds and publishes the Bitty Buddies website at https://bitty-buddies.github.io/

The website's source is in [Bitty-Buddies/bitty-buddies](https://github.com/Bitty-Buddies/bitty-buddies) under `site/`. This repo's workflow checks that out, builds it with the app's sprites and publishes it every hour, or straight away from the Actions tab.
